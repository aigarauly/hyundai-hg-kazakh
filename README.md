# Hyundai Grandeur HG - Қазақша локализация

Проект добавления казахского языка в штатную мультимедийную систему Hyundai Grandeur HG.

## Целевая система
- Android 2.3.4
- Исследуемая версия: `ST.HG.KR.E547.220425`
- Целевой язык: `kk_KZ`
- Сохранить без изменений существующие русский, английский и корейский языки

## Задачи
1. Проверить структуру `Settings.apk`, `Settings.odex` и обработчик `LocalePicker`.
2. Добавить отдельные ресурсы `res/values-kk/strings.xml` на основе согласованных переводов.
3. Проверить, что казахский язык появляется в списке выбора языка.
4. Собрать и проверить патч без установки на автомобиль до завершения тестирования.

## Ограничения
- Не заменять `ru_KZ` на `kk_KZ` двоичной подменой.
- Не менять существующие локализации.
- Не публиковать исходные системные образы, APK, ODEX и коммерческие шрифты без разрешения.
- Ни один файл этого репозитория пока не является готовой прошивкой для установки.

## Инструменты
Для анализа DEX предполагается использовать [baksmali/smali](https://github.com/baksmali/smali/releases). Проверка совместимости и фактическая сборка ещё требуются.
