# Правила казахской локализации

- Новый язык: `kk_KZ`, отображаемое название: `Қазақша`.
- Русский, английский и корейский интерфейсы остаются без изменений.
- Переводить только строки, у которых есть русский исходный вариант.
- Не переводить имена продуктов, протоколов и технологий: Android Auto, Apple CarPlay, Bluetooth, USB, Lexicon.
- Сохранять идентификаторы ресурсов, плейсхолдеры, XML-экранирование и порядок параметров.

## Согласованная терминология
| Русский смысл | Казахский вариант |
| --- | --- |
| Настройки | Баптаулар |
| Подключения | Жалғанулар |
| Подключение устройств | Құрылғыларды жалғау |
| Настройки подключения телефона | Телефонды жалғау баптаулары |
| Настройки трансляции экрана | Экран трансляциялау баптаулары |
| Проекция телефона | Телефон проекциясы |
| Память | Жады |
| Кнопка | батырма |
| Цифровой | Цифрлық |

Согласованный перевод находится в рабочих материалах и должен быть проверен перед импортом в этот репозиторий.
